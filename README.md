# Data Preprocessing and Normalization

## Overview

This project demonstrates Min-Max normalization and Z-score standardization using a sample dataset containing hours studied and corresponding marks.

## Technologies Used

- Python
- Pandas
- scikit-learn

## Techniques Implemented

**Min-Max Normalization:** Scales numerical values to a range between 0 and 1.

**Z-Score Standardization:** Transforms numerical values so that each feature has a mean of approximately 0 and a standard deviation of approximately 1.

## Dataset

The sample dataset contains two features:
- **Hours_Studied:** Number of hours spent studying.
- **Marks:** Marks obtained by the student.

## How to Run

Install the required libraries:

`pip install pandas scikit-learn`

Run the Python script:

`python normalization.py`

## Learning Outcomes

- Understand the difference between normalization and standardization.
- Apply both techniques using scikit-learn.
- Observe how numerical features change after transformation.
